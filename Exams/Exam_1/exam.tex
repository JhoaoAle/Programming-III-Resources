\textbf{3. (2.5)} Escribir un predicado \texttt{par\_impar/2} que genere una secuencia desde 1 hasta un número entero positivo \texttt{N}, donde \texttt{par\_impar(N, Resultado).} es verdadero si
\texttt{Resultado} es una lista de longitud \texttt{N} que contiene el valor correspondiente para cada número \texttt{i} desde \texttt{1} hasta \texttt{N}. \newline

Para cada posición \texttt{i} en la lista: 

\begin{itemize}
  \item Si \texttt{i} es múltiplo de \texttt{2} y \texttt{3}, el elemento debe ser \texttt{"Especial"}.
  \item Si \texttt{i} es par, el elemento debe ser \texttt{"Par"}.
  \item Si \texttt{i} es impar, el elemento debe ser \texttt{"Impar"}.
\end{itemize}


Ejemplo de consulta:
\begin{verbatim}
    ?- par_impar(15, R).
\end{verbatim}

Resultado esperado:
\begin{verbatim}
    R = ["Impar", "Par", "Impar", "Par", "Impar", "Especial", "Impar", "Par", "Impar", "Par", 
    "Impar", "Especial", "Impar", "Par", "Impar"].
\end{verbatim}
